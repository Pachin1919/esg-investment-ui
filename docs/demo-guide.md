# Verdant · 绿色值投资分析 Demo

## 打开页面

在项目根目录运行 `npm run dev`，保持终端运行。

- 绿色首页：<http://127.0.0.1:4319/>，说明公司环保表现与成本、转型风险及收益预期的关系。
- 蓝色工作台：<http://127.0.0.1:4319/app>，承载分析和模拟功能。
- 首页的 Try demo 使用虚构持仓；Analyze my portfolio 打开 CSV 导入流程。

这两个页面是不同功能区，不是两套可随意切换的工作台主题。

## 五步演示

1. **导入持仓**：上传 CSV，检查解析出的资产、当前市值和币种。可下载模板或使用虚构样例。导入金额不是历史买入成本；基金与现金也保留在组合中。
2. **设置偏好**：风险承受度与绿色偏好均为 Level 1–5。风险颜色依次为绿、蓝、黄、橙、红；Level 5 表示更高承受度，而不是更好的投资。绿色 Level 5 表示更重视环保公司。
3. **查看股票推荐**：搜索样例公司，打开详情查看 Expected return 与 E-score。候选明确标注为虚构例子，不是已经过偏好模型筛选的真实推荐。
4. **模拟投资**：选择某只候选股票，输入拟投资金额。可新增资金，或指定现有资产的减持金额并补充资金。减持金额与补充资金之和必须等于拟投资金额。演示模式另支持按虚构价格输入整数单位数。
5. **比较新旧组合**：查看组合金额、预期收益、绿色评分、覆盖率和持仓权重的变化。原组合不被修改；修改输入会清除旧结果。窄屏表格可横向滑动。

## 导入与币种

标准模板包含 `stock_code,exchange,company_name,current_holding_value,currency,as_of_date`。

也支持截图中的交易平台 CSV：`Ticker`、`Name`、`Asset Class`、`Total Market Value (SEK)` 等字段。当市值列明确标注 SEK 时，所有市值都视为已换算到 SEK，不能再按股票原始币种重复换算。

报告币种可选择 HKD、USD、CNY、TWD、SEK 及文件中的币种。跨币种转换需要手工提供估值日汇率；没有联网获取实时汇率。数字使用小数点，含逗号的公司名称或千位分隔值需要 CSV 引号。缺少必要列、非法金额、列数不匹配和混合估值日期会报错。

## 真实数据与演示的边界

- 实际导入后可展示市值及权重，但不从公司名称推断 E-score 或预期收益。
- Try demo 使用 `docs/api-examples/` 中的虚构持仓和候选数据；本地加权结果只是流程演示，不是后端模型。
- 预期收益暂按年度展示，最终预测期限、币种、分红及费用口径仍需确认。
- E-score 越高仅表示越环保，不保证收益更高。演示量表为 0–10，最终量表与组合聚合方法待确认。
- 波动率保持 Unavailable。没有气泡图、历史趋势或行业对比，不使用 E_weight 或旧 greenness 公式。
- 真实推荐与模拟分析仍等待 API。导入组合的模拟只能预览市值、权重和待发送请求，不会伪造分析结果。

## 保存、隐私与交接

CSV 在浏览器本地解析，持仓、偏好及草稿保存在 localStorage，刷新后可恢复。Export portfolio 导出当前组合；Clear portfolio 清除本地持仓和模拟记录。没有交易平台连接、下单或支付。

- `src/App.tsx`：绿色首页与工作台入口。
- `src/Workbench.tsx`：五步工作流、详情、对话框和比较。
- `src/portfolio.ts`：CSV 校验、币种归一化和本地演示计算。
- `src/analysis.css`：指标、风险颜色、可读性与响应式补充。
- [暂定接口与 JSON 样例](api-examples/README.md)：用于前后端讨论，不是已经上线的接口。
